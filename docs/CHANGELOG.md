[1.0.0] - 2026-10-16

Agregado

Se creó el juego Piedra, Papel o Tijera en C++.

Se agregó un menú principal con las opciones de jugar, ver el historial y salir.

Se implementó la elección aleatoria de la computadora.

Se agregó la comparación de las elecciones para determinar el resultado de cada partida.

Se creó la estructura Partida para guardar los datos de cada juego.

Se agregó la función para guardar las partidas en un archivo de texto.

Se agregó la función para leer y mostrar el historial de partidas.

Se incorporó la persistencia de datos para conservar el historial entre ejecuciones.

Se prepararon el manual de usuario, el manual de programador y el archivo README.
